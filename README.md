# 🐍 Python Object-Oriented Programming

A collection of notes, examples, and practice exercises completed while learning **Object-Oriented Programming (OOP)** in Python. This repository documents my progress as I build a strong foundation in object-oriented design and Python's OOP features.

## ✨ Topics Covered

* 🚗 Classes and Objects
* 🎓 Class Variables
* 👨‍👦‍👦 Inheritance
* 🐟 Multiple Inheritance
* 👻 Abstract Classes
* 🔴 `super()`
* 🎭 Polymorphism
* 🦆 Duck Typing
* 📚 Aggregation
* 🚘 Composition
* 📛 Nested Classes
* ⚡ Static Methods
* 🏫 Class Methods
* 🌟 Magic Methods
* ⚙️ `@property` Decorator

## 📂 Repository Structure

Each folder contains example programs exploring a specific OOP concept. The code is heavily commented and designed to reinforce understanding through practical examples.

## 🎯 Learning Objectives

Through this repository, I explored how to:

* Design reusable classes and objects.
* Model real-world relationships using inheritance and composition.
* Apply abstraction and polymorphism to write flexible code.
* Understand Python-specific OOP features such as magic methods, decorators, and duck typing.
* Write cleaner and more maintainable object-oriented programs.
